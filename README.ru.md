# Mycel

Общая живая карта проекта — для вас и ваших AI-агентов. [English](README.md)

![Карта проекта в Mycel: концепции с механикой внутри, связи, заметка, пройденные и упавшие проверки, что агент делает сейчас](docs/screenshot.png)

Mycel — локальное веб-приложение со свободной картой: блоки, заметки-стикеры, подкарты внутри блоков и связи между ними. Агент (Claude Code, Codex, Cursor, Gemini, локальная модель и другие) сам подключает папку проекта, читает код и строит карту у вас на глазах. Сверху — из каких частей состоит продукт, внутри каждой части — как она работает простыми словами, ниже — техника и код.

Дальше карта остаётся живой. Агент показывает, что делает сейчас и какие блоки меняет. Блоки, файлы которых изменились, помечаются «устарел?». Проверки окрашивают блоки в зелёный или красный по ходу тестов. Ваши правки на карте агент получает перед следующим шагом.

## Зачем

- **Весь проект одним взглядом.** Ползунок переключает четыре уровня: *концепция* и *механика* — простыми словами, понятно без программирования; *техника* и *код* — для разработчиков.
- **Разговор о блоках, а не о файлах.** Выделите блок и скажите агенту «сделай вот это здесь» — агент видит выделение.
- **Видно, что происходит.** Что агент делает сейчас и какие блоки правит. Видно и устаревшие описания, блоки без проверки, упавшие тесты и забытые `TODO`.
- **План на карте.** Агент предлагает изменения пунктиром, вы принимаете или отклоняете. Блоки, добавленные вами, становятся планом для агента.
- **Локально и просто.** Один процесс Node.js, без зависимостей, сборки, облака и ключей. Данные хранятся в `.mycel/` рядом с программой, в папки проектов Mycel ничего не пишет.

## Быстрый старт

Нужен [Node.js](https://nodejs.org) 22 или новее.

```bash
git clone https://github.com/mathew5612/mycel.git
cd mycel
node mycel.mjs open
```

Mycel запустится в фоне и откроет http://127.0.0.1:4317. В Windows можно дважды щёлкнуть `Mycel.cmd`. В macOS — `Mycel.command`; перед первым запуском один раз выполните `chmod +x Mycel.command`.

Потом откройте агента в **папке своего проекта** и дайте ему строку ниже. Её копирует строка «Агенту» вверху главной страницы Mycel.

```text
Прочитай инструкцию Mycel и выполни её: curl -s http://127.0.0.1:4317/agent
```

В PowerShell — `curl.exe` вместо `curl`. Агент подключит папку и настроится: в Claude Code поставит плагин Mycel и попросит начать новую сессию. Потом он построит карту. Разговаривать с агентом вы продолжаете в его окне — чата в Mycel нет.

Чтобы обновить Mycel, выполните `git pull`, затем `node mycel.mjs open`. Если работает прежняя версия с теми же данными, `open` её перезапустит. Карты в `.mycel/` не затрагиваются.

## Для AI-агентов

Если человек попросил настроить Mycel для его проекта:

1. Проверь Node.js 22+: `node --version`.
2. Если Mycel ещё не запущен (`curl -s http://127.0.0.1:4317/api/health`), склонируй его **вне** проекта, например в `~/mycel`, и запусти: `node ~/mycel/mycel.mjs start`. Один Mycel обслуживает все проекты компьютера.
3. Получи инструкцию — `curl -s http://127.0.0.1:4317/agent` или `node ~/mycel/mycel.mjs guide` — и выполни её из папки проекта. В ней готовые команды для этого компьютера.
4. Скажи человеку открыть http://127.0.0.1:4317, чтобы он видел карту.

Как подключаются агенты:

| Агент | Подключение |
| --- | --- |
| Claude Code | `node <mycel>/mycel.mjs plugin --install`: инструменты MCP, хуки (отмечают изменённые файлы) и обзор карты в начале сессии |
| Codex, Cursor, Gemini / Antigravity, VS Code, Windsurf, Cline, Claude Desktop | `node <mycel>/mycel.mjs plugin --agent <имя>` печатает запись MCP и куда её положить |
| Локальные модели (Ollama, LM Studio, llama.cpp, vLLM) | `node <mycel>/mycel.mjs chat`: встроенный агент со всеми инструментами Mycel и чтением файлов проекта. Настройки клиентов — `plugin --agent lmstudio\|continue\|goose\|opencode\|jan\|openwebui` |
| Любой другой | Командная строка (`node <mycel>/mycel.mjs <команда>` из папки проекта), описания функций (`mycel tools --format openai\|mcp`, `mycel call <инструмент> '<json>'`) или HTTP API |

Главные команды; полный список — `node mycel.mjs --help`:

```bash
node mycel.mjs init              # подключить текущую папку (та же папка — тот же проект и карта)
node mycel.mjs context --brief   # вся карта в Markdown, что человек выделил и сделал
node mycel.mjs build map.json    # построить структуру по шагам, расстановка сама
node mycel.mjs apply ops.json    # пакет операций поверх прочитанной ревизии
node mycel.mjs wait              # ждать действия человека в Mycel или чужой правки
node mycel.mjs doing 'читаю server.mjs' --progress 40
node mycel.mjs mark cart passed  # plan | testing | passed | failed | none
node mycel.mjs check             # запустить проверки блоков, рамки окрашиваются по ходу
node mycel.mjs watch             # отмечать блоки, чьи файлы меняются, кто бы их ни менял
node mycel.mjs health            # красные, устаревшие, без проверки, план; TODO и похожее на ключи
```

## Работа с картой

- **Создание:** правый клик по пустому месту — блок или заметка; по блоку — блок внутри него.
- **Связь:** потяните за любой край блока (или с Alt из любого места) и отпустите в любом месте другого блока.
- **Навигация:** двойной клик по блоку с подкартой погружает в него, Esc поднимает обратно. Ползунок внизу сворачивает карту по уровням.
- **Передать правки агенту:** «Закончить правки» отправляет агенту все ваши изменения одним событием.
- **Предложения:** предложения агента видны пунктиром с подсветкой, внизу — «Принять» и «Отклонить».
- **История и здоровье:** «История» показывает последние 200 изменений с автором и причиной, «Здоровье» подсвечивает, что требует внимания.

## Виртуальные машины

Агенты в виртуальной машине (VMware, VirtualBox, Hyper-V, WSL) работают с Mycel на основной машине:

- **На основной машине:** `node mycel.mjs remote on`.
- **Агент в виртуальной машине выполняет:** `curl -fsS http://<адрес основной>:4317/install.sh | sh`. Скрипт ставит Node.js, если его нет, и копию Mycel, затем просит доступ с кодом из четырёх цифр.
- **Вы:** сверяете код и нажимаете «Разрешить». У каждой машины свой ключ, его можно отозвать.

## Приватность и безопасность

- Mycel слушает только `127.0.0.1`. Доступ для виртуальных машин выключен, пока вы не выполните `mycel remote on`; он работает только на адресах виртуальных сетей и только с ключом машины, который вы одобрили.
- Запись через API — только с токеном из `.mycel/token`.
- Mycel ничего никуда не отправляет. Сеть используют только:
  - `mycel chat` — обращается к серверу модели, который вы указали;
  - установщик для виртуальной машины — скачивает Node.js с nodejs.org и проверяет SHA-256.
- Проверки Mycel и встроенный агент для локальных моделей не открывают `.env`, ключи и сертификаты. В отчётах о рисках — только файл и номер строки.

## Разработка

```bash
node --test test/*.test.mjs
```

Тесты интерфейса идут в headless Chrome; без Chrome они пропускаются (путь можно задать в `MYCEL_CHROME`). Сборки нет. После правок `public/` обновите страницу. После правок сервера выполните `node mycel.mjs stop`, затем `node mycel.mjs open`. Тесты используют временные папки и свободные порты, ваш `.mycel/` не трогают.

Mycel на ранней стадии (0.21). Замечания и pull request'ы приветствуются.
