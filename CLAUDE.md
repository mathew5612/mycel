# Mycel

Read CONCEPT.md, PROJECT_STATE.md and AGENTS.md first. They hold the user's latest requirements, the current state and the rules for working on the project. README.md is the short description for everyone (in English; README.ru.md is the same in Russian); docs/reference.md describes in detail how to run Mycel, the app with projects, the agent commands and the API; src/agent-guide.md is the guide the agent gets at `/agent`. The current version is one app with a list of projects and nested blocks, with no links to code, no fixed level categories and no permanent right-hand panel.
