# Mycel

Сначала прочитай CONCEPT.md, PROJECT_STATE.md и AGENTS.md. Они содержат последние требования пользователя, текущее состояние и правила работы с проектом. README.md — короткое описание для всех (по-английски, README.ru.md — по-русски); docs/reference.md подробно описывает запуск, приложение с проектами, команды агента и API; src/agent-guide.md — инструкцию, которую агент получает по адресу `/agent`. Текущая версия — одно приложение со списком проектов и вложенными блоками без привязок к коду, фиксированных категорий уровней и постоянной правой панели.
